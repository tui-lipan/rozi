# rozi documentation

rozi is a terminal multiplexer for local, remote, and agent-driven development. It tiles terminal
panes, keeps named sessions running after you leave, connects to other machines over SSH, and shows
which coding agents need your input.

These pages are also published at [rozi.tui-lipan.dev](https://rozi.tui-lipan.dev).

## Where to start

- [Getting started](getting-started.md) walks through a first session in a few minutes.
- [Installation](installation.md) covers install, update, and rollback on every platform.
- [Core concepts](core-concepts.md) explains the terms used throughout the documentation.
- [Keybindings](keybindings.md) lists the default keys.
- [Customize rozi](customize.md) shows how to change themes, layouts, pane styles, and keys.
- [Configuration](configuration.md) is the `config.toml` reference.

The [documentation overview](overview.md) lists every guide with a short description.
