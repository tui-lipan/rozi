COMMANDS                                           *hyprmux-navigator-commands*

                                                *:HyprmuxNavigateLeft*
:HyprmuxNavigateLeft       Move to the split or hyprmux pane on the left.
                                                *:HyprmuxNavigateDown*
:HyprmuxNavigateDown       Move to the split or hyprmux pane below.
                                                *:HyprmuxNavigateUp*
:HyprmuxNavigateUp         Move to the split or hyprmux pane above.
                                                *:HyprmuxNavigateRight*
:HyprmuxNavigateRight      Move to the split or hyprmux pane on the right.
                                                *:HyprmuxNavigatePrevious*
:HyprmuxNavigatePrevious   Move to the previous split or hyprmux pane.
                                                *:HyprmuxNavigatorCheck*
:HyprmuxNavigatorCheck     Print diagnostics and test focus-left through the
                           hyprmux control socket.

The default normal-mode mappings are CTRL-H, CTRL-J, CTRL-K, CTRL-L, and
CTRL-\. The four directional mappings also work from terminal mode.

==============================================================================
CONFIGURATION                                       *hyprmux-navigator-config*

Set before the plugin loads:

                                                *g:hyprmux_navigator_command*
g:hyprmux_navigator_command
        Path to the hyprmux executable. Defaults to "hyprmux" from PATH.

                                                *g:hyprmux_navigator_no_mappings*
g:hyprmux_navigator_no_mappings
        Set to 1 to define commands without installing default mappings.

                                                *g:hyprmux_navigator_save_on_switch*
g:hyprmux_navigator_save_on_switch
        0: do not save (default)
        1: update the current buffer before leaving Vim
        2: write all changed buffers before leaving Vim

                                                *g:hyprmux_navigator_wrap*
g:hyprmux_navigator_wrap
        Set to 1 to wrap to another hyprmux pane when no pane exists in the
        requested direction. The default is 0, which leaves focus unchanged
        at the outer edge.

The plugin invokes `hyprmux run-action` only when movement reaches an editor
edge. It uses ROZI_SOCKET from the pane environment.
