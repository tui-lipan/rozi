# Extension gallery

Public extensions listed in the [extension index](https://tui-lipan.github.io/rozi-extension-index/v1/index.json),
the same list **Discover** shows inside `rozi`. To install one, copy its command or open the command
palette, choose **Extensions…**, and switch to **Discover**.

Listed extensions are not reviewed. **Trusted** marks extensions maintained by the `rozi` author.
Read an extension's source before you install it; see
[Review an extension before installing](extensions.md#review-an-extension-before-installing).

## Add your extension

Any public GitHub repository with `extension.toml` at its root and the `rozi-extension` topic is
listed within an hour. Add `screenshots` to the manifest to show images on its card. See
[Publish to Discover](writing-extensions.md#publish-to-discover).
